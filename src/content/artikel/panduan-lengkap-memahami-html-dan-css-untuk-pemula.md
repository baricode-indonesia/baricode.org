Setiap halaman web yang kamu buka di internet dibangun menggunakan HTML dan CSS. Keduanya adalah dua fondasi wajib sebelum melangkah ke JavaScript atau framework modern.

## Apa itu HTML?

HTML (_HyperText Markup Language_) berfungsi sebagai kerangka atau penopang dari sebuah halaman web.

```html
<!DOCTYPE html>
<html lang="id">
	<head>
		<title>Situs Pertamaku</title>
	</head>
	<body>
		<h1>Halo Dunia!</h1>
		<p>Ini adalah halaman web pertamaku.</p>
	</body>
</html>
```

## Apa itu CSS?

CSS (_Cascading Style Sheets_) bertanggung jawab menghias kerangka HTML tersebut dengan warna, tata letak (_layout_), font, dan responsivitas layar.

```css
body {
	background-color: #0b0f17;
	color: #ffffff;
	font-family: sans-serif;
}
```
